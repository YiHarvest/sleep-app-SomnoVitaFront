# 历史版本归档与查看引导

- 标签：
  - v-0505-Initial_prototype
  - v-0515-Intermediate_update
  - v-0524-Stable_baseline

## 查看方式
- 命令行：
  - `git log --oneline --decorate --graph`
  - 切换到快照：`git checkout tags/v-0505-Initial_prototype`（或 0515 / 0524）
- GitHub 页面：
  - Commits 列表按上述顺序展示
  - Tags 页面可直接跳转到各快照

> 说明：history-archive 分支仅保留引导文档，不重复存放历史版本的整份代码。
